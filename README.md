# MyRPGGame

## Описание проекта
Данный проект представляет собой пошаговую систему боя и управления отрядом персонажей (RPG Game System), реализованную на C++ (с графическим интерфейсом на SFML + ImGui), а также модуль Лабораторной работы 3 на C# (.NET 9).

## Технологический стек
* **Языки программирования:** C++ (C++20), C# (.NET 9)
* **Библиотеки C++:** SFML 2.6.1, Dear ImGui, ImGui-SFML
* **Система сборки:** CMake, .NET CLI (dotnet)
* **Контроль версий:** Git / GitHub 

---

## Лабораторная работа 3: «Язык программирования с управляемой памятью. Умные указатели»

### Часть 1. Реализация на C# (.NET 9)
Проект расположен в каталоге `csharp/`:
* `SkillTemplate.cs` — шаблон умения с валидацией кулдауна.
* `WeaponTemplate.cs` — шаблон оружия со свойствами урона и методом `Upgrade()`.
* `CharacterTemplate.cs` — шаблон персонажа (композиция `_innateSkill`, агрегация `_activeWeapon`).
* `CombatStats.cs` — структура (`struct`) для демонстрации передачи типов-значений.
* `BattleSession.cs` — освобождение ресурса без деструктора (`IDisposable` + `using`).
* `Program.cs` — сценарий ЛР 2 и демонстрации памяти (ссылки/копии, using, GC и WeakReference).

**Команды сборки и запуска C#:**
```bash
# Сборка проекта
dotnet build csharp

# Запуск программы
dotnet run --project csharp
```

### Часть 2. Реализация на C++ (Умные указатели)
В проекте на C++ полностью устранены сырые указатели `new` и `delete`, управление памятью переведено на умные указатели `std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`.

#### Таблица владения памятью:
| Где был указатель | На что указывает | Кто владеет | Заменяется на | Почему |
| :--- | :--- | :--- | :--- | :--- |
| `CharacterTemplate::activeWeapon` | `WeaponTemplate` (активное оружие) | Глобальный инвентарь / база (персонаж не владеет) | `std::weak_ptr<WeaponTemplate>` | Персонаж использует оружие, но не управляет его временем жизни. `weak_ptr` защищает от повисших указателей. |
| `WeaponTemplate* shelf[3]` (динамический массив) | Массив объектов оружия | Внешняя область видимости (один владелец) | `std::unique_ptr<WeaponTemplate[]>` / `shelf[3]` | Единоличное владение массивом; автоматическое освобождение памяти без `delete[]`. |
| Временный создаваемый предмет | Экземпляр оружия | Создатель объекта (один владелец) | `std::unique_ptr<WeaponTemplate>` | Монопольное владение; передача через `std::move`. |
| Реестр базы данных (`weapons`) | Шаблоны оружия | Разделяемое владение (база, отряды) | `std::shared_ptr<WeaponTemplate>` | Совместное использование одного объекта несколькими системами. |

**Команды сборки и запуска C++:**
```bash
# Конфигурация CMake
cmake -B build -S .

# Сборка всех целей (основная игра и демонстрация ЛР 3)
cmake --build build --config Debug

# Запуск консольной демонстрации умных указателей (ЛР 3)
build\Debug\Lab3Demo.exe

# Или запуск основной игры с флагом демонстрации
build\Debug\MyRPGGame.exe --lab3

# Запуск основной графической игры
build\Debug\MyRPGGame.exe
```
