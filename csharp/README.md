# Лабораторная работа 3. Часть 1 (C# - Управляемая память)

## Проект: RPG Game System

Программа представляет собой перенос предметной области из Лабораторной работы 2 на язык C# с управляемой памятью (.NET 9).

### Структура классов
* `SkillTemplate.cs` — шаблон умения с валидацией кулдауна (не может быть отрицательным) и расчетом динамического урона.
* `WeaponTemplate.cs` — шаблон оружия со свойствами `CurrentDamage` (+8% за уровень заточки) и методом `Upgrade()` (ограничение максимум 20-й уровень).
* `CharacterTemplate.cs` — шаблон персонажа:
  * **Композиция:** поле `_innateSkill` (`SkillTemplate`) создается внутри конструктора и не выдается наружу.
  * **Агрегация:** поле `_activeWeapon` (`WeaponTemplate?`) передается извне через `EquipWeapon()`.
  * **Проверка правила:** атака `PerformAttack()` запрещена без экипированного оружия.
* `CombatStats.cs` — тип-значение (`struct`) для демонстрации отличий передачи по значению от ссылочных типов (`class`).
* `BattleSession.cs` — класс управления ресурсом без деструктора через интерфейс `IDisposable` и оператор `using`.
* `Program.cs` — сценарий предметной области и 3 демонстрации работы с управляемой памятью.

---

### Сборка и запуск из командной строки

Требуется установленный .NET SDK (версия 8.0 или 9.0).

#### 1. Сборка проекта
```bash
dotnet build csharp
```

#### 2. Запуск программы
```bash
dotnet run --project csharp
```

#### 3. Очистка временных файлов сборки
```bash
dotnet clean csharp
```
